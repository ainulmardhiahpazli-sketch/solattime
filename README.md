# SolatTime

A simple prayer time desktop app built with Electron (HTML, CSS, JavaScript, JSON, external APIs and Local Storage).
Made for CSC2923 Object Oriented Programming - Final Assignment.

## Features
- **Home:** prayer times, Hijri date, next prayer countdown, suggested activity, Qibla direction, ayah of the day
- **Reminders:** add, view, edit and delete activity reminders (saved in Local Storage)
- **Khatam Planner:** calculates when you will finish the Quran and if you can finish before Ramadan

## APIs used (no API key needed)
- Aladhan API - https://aladhan.com/prayer-times-api (prayer times, Hijri date, Qibla, Hijri/Gregorian conversion)
- Al-Quran Cloud API - https://alquran.cloud/api (ayah of the day)

## How to run
1. Install Node.js (https://nodejs.org)
2. Open a terminal in this folder
3. Run `npm install`
4. Run `npm start`
